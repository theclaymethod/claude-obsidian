# Claude Obsidian Assistant

A starter Obsidian vault wired for Claude Code. Ships a Johnny Decimal folder structure, a `/obsidian` skill that syncs project state into the vault, five CSS themes, and a `CLAUDE.md` that gives Claude context on how the vault works. No plugins or build steps — everything is plain markdown, CSS, and JSON.

**Location:** `/Users/claytonkim/dev/claude-obsidian-assistant`
**GitHub:** git@github.com:nemocake/claude-obsidian-assistant.git

---

## Stack

| Layer | Tech | Purpose |
|-------|------|---------|
| Platform | Obsidian | Vault UI, canvas rendering, Dataview queries |
| Skill | SKILL.md (Agent Skills spec) | `/obsidian` command for Claude Code |
| Theming | CSS Snippets | 5 self-contained themes with sidebar icons and color coding |
| Content | Markdown + YAML frontmatter | All vault files, project entries, templates |
| Diagrams | Obsidian Canvas (JSON) | Architecture diagrams, vault map |

Pure content repo — no runtime, no dependencies, no build step.

---

## Architecture

### Core Systems

`/obsidian` skill invoked from any project dir -> Codebase analysis -> Action menu -> Vault file writes

### Data Flow
1. User runs `/obsidian` from a project directory
2. Skill resolves vault path from `<skill-path>` (symlink to this repo)
3. Scans `11 Active/` for matching project file by path, name, or keywords
4. Analyzes codebase: package.json, git log, directory structure
5. Presents action menu (create, update, dev log, canvas, vault map)
6. Writes markdown/JSON files into the vault's Johnny Decimal structure
